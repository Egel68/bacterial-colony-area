## Why

Текущий фреймворк оценки алгоритмов (`run_baseline`) сохраняет результаты в JSON только во временную директорию. Результаты не отслеживаются в git, не привязаны к версии кода, и каждый прогон перезаписывает предыдущий. При изменении алгоритмов, данных или параметров невозможно воспроизвести старые результаты — теряется история изменений качества. Нет единой точки входа "dataset → preprocessing → run → report", которая делает pipeline воспроизводимым.

## What Changes

- Создать единый entry point `uv run evaluate`, который последовательно выполняет: импорт датасета (если нужно), загрузку данных, прогон алгоритмов, расчёт метрик, генерацию отчёта
- Сохранять каждый результат прогона в структурированную директорию `evaluations/<run-id>/`, которая содержит JSON-отчёт, HTML-визуализацию и дайджест с git-commit-id и конфигурацией
- Добавить поддержку конфигурационных файлов (YAML), чтобы параметры прогона были явными и воспроизводимыми
- Генерировать HTML-дайджест с Chart.js графиками (из имеющегося `dashboard.py`) для каждого прогона
- Закрепить импорт датасета (CocoBboxImporter) в общем pipeline с возможностью пропустить при наличии готового `dataset.json`

## Capabilities

### New Capabilities
- `reproducible-evaluation`: Единый воспроизводимый pipeline оценки алгоритмов: конфигурация → импорт данных → прогон → сохранение результатов в git-tracked директории → HTML-визуализация.

### Modified Capabilities
- `classical-baseline-evaluation`: расширяется требование хранения результатов (run-id, git-commit, конфиг) и интеграция в общий pipeline.

## Impact

- `testing/evaluator.py` — новый модуль: единый точка входа pipeline, парсинг YAML-конфига, run-id generation
- `testing/__main__.py` — CLI `uv run evaluate`
- `testing/dashboard.py` — доработка generate_report для использования в pipeline
- `pyproject.toml` — новый entry point `evaluate`
- `.github/workflows/` — опционально CI-прогон по расписанию
- `evaluations/` — git-tracked директория с результатами прогонов (исключая бинарные артефакты)
- `.gitignore` — настройка для `evaluations/`
