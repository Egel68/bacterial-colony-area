# Proposal

## Why

Проекту нужен привычный GitHub workflow, но Git LFS хранит переданные файлы как есть и сам по себе не упаковывает набор в компактный архив. Сейчас исходные 369 COCO-фотографий уже находятся локально и проходят проверку, однако `train-colony` создаёт маски, split и чёрнофоновые варианты в подготовительной стадии запуска; их нужно заранее собрать в проверенный обучающий набор и без потерь упаковать для передачи.

## What Changes

- Добавить локальную предварительную проверку и подготовку обучающего набора: проверить наличие и читаемость всех размеченных COCO-изображений, создать маски, фиксированный split и необходимые чёрнофоновые варианты до упаковки и загрузки.
- Хранить в Git LFS lossless-архив обучающего набора в формате `.tar.zst`, а не распакованные копии бинарных файлов; небольшие манифесты и аннотации оставить доступными в обычном Git. Перед отправкой проверять состав и фактический размер архива.
- Изменить workflow `train-colony`: обучающий запуск должен использовать заранее подготовленный и локально распакованный набор, не создавая и не записывая файлы изображений или масок. Выбор фрагментов и случайные аугментации могут по-прежнему выполняться в памяти во время обучения.
- Документировать проверку исходных файлов, подготовку, упаковку/распаковку, получение архива через Git LFS, квоты GitHub и проверку лицензий.
- Оставить `test_images/` в обычном Git и сохранить игнорирование сгенерированных результатов обучения. Не добавлять, не коммитить и не отправлять локальные датасеты автоматически.

## Capabilities

### New Capabilities

- `dataset-distribution`: Локальная проверка и подготовка обучающих данных, их сжатое хранение в Git LFS и получение из репозитория.

### Modified Capabilities

- `colony-model-training`: Обучение использует заранее материализованный набор вместо создания файлов изображений и масок во время запуска.

## Impact

- Конфигурация репозитория: `.gitattributes` для архивов `.tar.zst`, правила `.gitignore` для распакованных рабочих каталогов.
- Обучающий конвейер: отдельный этап подготовки/проверки данных и использование его результата при обучении.
- Документация: `README.md`, `AGENTS.md` и руководства по датасетам и обучению.
- Новая Python-зависимость не ожидается: `zstandard` уже включён в дополнительное окружение `dev`, используемое полным обучающим окружением. Архивирование не должно изменять пиксели исходных изображений или масок.
