# Встроенные нейросетевые модели

В эту папку помещаются обученные ONNX-модели (`*.onnx`), которые упаковываются
в исполняемый файл при сборке Nuitka и автоматически регистрируются как
алгоритмы детекции при запуске приложения (имя вида `NN:<stem>`).

- Файлы `*.onnx` отслеживаются git (как и остальные .onnx в проекте).
- Файлы весов PyTorch (`*.pt`, `*.pth`) сюда класть НЕ нужно — они игнорируются.
- Для пользовательского анализа требуется bundled `models/colony_seg.onnx`; если эта утверждённая модель отсутствует или не загружается, приложение показывает ошибку и не выбирает замену.

Для внутренней разработки внешние модели (без пересборки) подключаются через кнопку «Загрузить модель (.onnx)»
в отдельном GUI testing module, не открываемом из главного пользовательского окна, либо через флаг `--model` в CLI.
