# Spec Delta

## MODIFIED Requirements

### Requirement: Testing window entry

Главное пользовательское окно SHALL NOT предоставлять действие для открытия GUI тестирования алгоритмов. Средство GUI тестирования может сохраняться для внутренних сценариев разработки и валидации, но не должно быть доступно через пользовательский путь приложения.

#### Scenario: Open from main window
- **WHEN** пользователь открывает главное окно приложения
- **THEN** он SHALL NOT видеть действие для открытия GUI тестирования алгоритмов

#### Scenario: Developer launches the internal window directly
- **WHEN** разработчик запускает модуль GUI тестирования отдельно от пользовательского приложения
- **THEN** открывается внутреннее окно тестирования с доступными зарегистрированными алгоритмами и функциями dev-сравнения

#### Scenario: Testing window is not exposed to application users
- **WHEN** пользователь открывает главное окно установленного приложения
- **THEN** он SHALL NOT видеть действие для открытия GUI тестирования алгоритмов

### Requirement: Algorithm selection in GUI

Пользовательский GUI SHALL NOT предоставлять список алгоритмов, управление выбором алгоритмов, парное сравнение альтернатив или загрузку внешних моделей. Существующая инфраструктура тестирования SHALL продолжать поддерживать выбор алгоритмов во внутренних автоматизированных тестах и CLI.

#### Scenario: Select subset
- **WHEN** внутренний инструмент тестирования снимает галочку с алгоритма и запускает прогон
- **THEN** этот алгоритм SHALL NOT запускаться и NOT отображаться в результатах

#### Scenario: Summary table shows algorithms
- **WHEN** прогон внутреннего инструмента завершён
- **THEN** таблица SHALL показывать по строке на каждый выбранный алгоритм со сводными метриками

#### Scenario: GUI does not expose alternative algorithms
- **WHEN** пользователь взаимодействует с приложением через поддерживаемый пользовательский GUI-сценарий
- **THEN** интерфейс SHALL NOT позволять выбирать классические алгоритмы или модели, отличные от встроенной `NN:colony_seg`

#### Scenario: External model loading is unavailable to users
- **WHEN** пользователь исследует пользовательские окна приложения
- **THEN** он SHALL NOT найти GUI-действие загрузки стороннего ONNX-файла

#### Scenario: Developer testing remains supported outside user GUI
- **WHEN** разработчик запускает внутренний CLI или автоматизированные тесты алгоритмов
- **THEN** существующая инфраструктура SHALL сохранять возможность выбирать алгоритмы для оценки
