# Bacteria Colony Area Analyzer v0.3.0

## Новое

- **Закреплённая модель распознавания.** Пользовательский анализ автоматически использует встроенную ONNX-модель `NN:colony_seg`; переключение алгоритмов и настройка параметров доступны только во внутренних инструментах разработки.
- **Коррекция области анализа.** Перед запуском распознавания можно перемещать круг чашки Петри и изменять его радиус.
- **Фоновая обработка интерфейса.** Загрузка изображений, поиск чашки, анализ, отрисовка, сохранение результатов и операции разметки выполняются без блокировки GUI; отображаются состояния и прогресс.
- **Ресурсно-адаптивные прогоны.** Внутренний конвейер тестирования получил планирование с учётом ресурсов, перекрытие этапов, телеметрию и профилирование.

## Улучшения

- Ускорено и сделано отзывчивее тестирование алгоритмов на больших изображениях; добавлены контрольные профили и критерии производительности.
- Улучшена разметка: локальное обновление изображения при рисовании, отбрасывание устаревших операций, кооперативная отмена и атомарное сохранение/экспорт.
- Обновлены документация, автоматические тесты и CI для Linux и Windows.

## Обновление

Запустите скачанный `BacteriaAnalyzer` (Linux) или `BacteriaAnalyzer.exe` (Windows). Для запуска из исходников используйте `uv sync`, затем `uv run bacteria-analyzer`.
