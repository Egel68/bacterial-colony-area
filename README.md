# 🔬 Bacteria Colony Analyzer

Десктопное приложение для анализа изображений чашек Петри: автоматический подсчёт колоний бактерий, ручная разметка ground-truth масок, тестирование алгоритмов, обучение нейросетевой сегментации.

---

## 📥 Установка

### Пользователям (бинарник)

Скачайте последний релиз со страницы [Releases](https://github.com/Egel68/bacterial-colony-area/releases):

| Платформа | Файл |
|---|---|
| Linux | `BacteriaAnalyzer` |
| Windows | `BacteriaAnalyzer.exe` |

Запустите файл — больше ничего устанавливать не нужно.

### Разработчикам (исходники)

Требуется Python 3.13+ и [uv](https://docs.astral.sh/uv/).

```bash
# Лёгкое окружение (~600 МБ) — для запуска и тестирования
uv sync
uv run bacteria-analyzer

# Полное окружение (~5 ГБ) — для обучения нейросети
UV_PROJECT_ENVIRONMENT=.venv-dev uv sync --extra dev
source .venv-dev/bin/activate
```

## 🔍 1. Анализ колоний

Автоматический подсчёт колоний бактерий на фотографии чашки Петри.

### Как использовать

1. Нажмите **«📂 Открыть»** и выберите изображение (PNG, JPG, BMP, TIFF, WebP).
2. Нажмите **«🔍 Анализировать»**.
3. Откроется окно анализа с изображением и панелью параметров.

### Параметры

| Параметр | Что делает |
|---|---|
| Чувствительность (1–100%) | Чем выше, тем меньше колоний детектируется |
| Контраст (0.5–3.0×) | Усиление контраста перед детекцией |
| Отступ от края (0–30%) | Сужение рабочей зоны от края чашки |
| Мин. размер (1–1000 px) | Отсеивает мелкий шум |
| Solid fill | Режим для сливного газона (заливка целиком) |

### Режимы просмотра

| Режим | Показывает |
|---|---|
| Результат | Оригинал + контуры найденных колоний |
| Оригинал | Исходное изображение |
| Предобработка | Зелёный канал после усиления контраста |
| Бинарная маска | Чёрно-белая маска найденных колоний |

### Кнопки

- **«💾 Сохранить результат»** — сохранить текущее изображение в PNG.
- **«Сбросить авто-детекцию»** — перезапустить поиск чашки Петри.
- **«Пересчитать»** — применить новые параметры.

## ✏️ 2. Разметка изображений (Labeling)

Ручное создание масок колоний для обучения и тестирования алгоритмов.

### Начало сессии

1. На главном экране нажмите **«✏️ Разметка тестовых изображений»**.
2. Выберите или создайте **папку сессии** — в ней будут храниться все файлы.

### Структура папки сессии

```
session_dir/
├── photo1.png, photo2.jpg, ...   ← исходные изображения
├── masks/                         ← маски исходников (*_mask.png)
├── cropped/                       ← обрезки чашек Петри (*_cropped.png)
└── cropped_masks/                 ← маски обрезков (*_cropped_mask.png)
```

### Интерфейс

**Левая панель:**

| Элемент | Назначение |
|---|---|
| «📁 Исходные изображения» / «✂️ Обрезки чашек» | Переключение между исходниками и обрезками |
| Список файлов | Клик для загрузки изображения |
| «🔄 Обновить» | Перечитать список файлов |
| «📂 Добавить изображения» | Выбрать файлы на компьютере → копируются в папку сессии |
| Центр X / Y, Радиус | Настройка положения чашки Петри |
| «🔍 Авто-поиск» | Автоматически найти чашку Петри |
| «✂️ Обрезать по чашке» | Вырезать чашку, залить фон чёрным |

**Панель инструментов (снизу):**

| Элемент | Назначение |
|---|---|
| − / `20 px` / + | Размер кисти (2–100px) |
| `100%` + / − / 1:1 | Зум (0.1× – 20×, колёсико мыши) |
| «🖼 Изображение + маска» / «🏁 Только маска» | Режим отображения |
| «✏️ Рисовать» / «🧹 Ластик» | Кисть рисует или стирает |
| «🗑 Очистить» | Сбросить всю маску |
| «💾 Сохранить маску» | Сохранить маску в `masks/` или `cropped_masks/` |
| «📦 Экспорт в ZIP» | Упаковать всю папку сессии в ZIP-архив |

### Типовой сценарий

1. **«✏️ Разметка»** → выбрать/создать папку.
2. **«📂 Добавить изображения»** → выбрать фото чашек Петри.
3. Выбрать файл из списка — чашка определяется автоматически.
4. Если авто-поиск не сработал: настроить вручную или нажать **«🔍 Авто-поиск»**.
5. (Опционально) Нажать **«✂️ Обрезать по чашке»** — программа вырежет чашку и переключится в режим обрезков.
6. Рисовать маску:
   - **«✏️ Рисовать»** — закрашивать колонии.
   - **«🧹 Ластик»** — стирать ошибки.
   - Колёсико мыши — зум.
7. **«💾 Сохранить маску»**.
8. Повторить для всех изображений.
9. **«📦 Экспорт в ZIP»** — выбрать место сохранения.
10. Отправить ZIP автору программы.

## 🧪 3. Тестирование алгоритмов (CLI)

Сравнение алгоритмов детекции на эталонных изображениях.

```bash
uv run test-algorithms
# или:
uv run test-algorithms --data-root ./test_images --output ./report.html
```

- Загружает пары «изображение + маска» из `test_images/`.
- Прогоняет 4 алгоритма: ClassicDefault, ClassicHighSensitivity, ClassicSolidFill, ClassicLowSensitivity.
- Считает метрики: IoU, Dice, F1, Precision, Recall, Accuracy.
- Генерирует HTML-отчёт с графиками Chart.js.
