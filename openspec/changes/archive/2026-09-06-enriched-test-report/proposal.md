## Why

Текущий HTML-отчёт тестирования показывает только среднее ± стандартное отклонение для каждой метрики. Этого недостаточно, чтобы уверенно ответить на вопрос «какой алгоритм реально лучше»: среднее может быть обманчивым при асимметричном распределении метрик по снимкам, нет способа оценить разброс и выбросы, нет статистической значимости различий между алгоритмами. Исследователю нужен полный набор дескриптивных статистик и инструментов сравнения.

## What Changes

- Расширение сводной таблицы: добавить median, IQR (Q1, Q3), min, max, 5-й и 95-й процентили для каждой метрики
- Добавить box-plot графики (Chart.js) для визуализации распределения метрик по алгоритмам
- Добавить per-sample scatter plot (точка = снимок) — наглядно видно разброс и выбросы
- Реализовать статистический тест (Wilcoxon signed-rank) для парного сравнения алгоритмов по каждой метрике — p-value и интерпретация «значимо лучше / нет значимых различий»
- Добавить таблицу «победитель по метрике»: для каждой пары алгоритмов подсчёт доли снимков, на которых один алгоритм лучше другого (с учётом источника)
- Добавить таблицу выбросов: снимки, где метрика алгоритма выходит за ±3σ от среднего
- Вывод сводной статистики в JSON для машинной обработки
- CLI-флаг `--stats` для влючения расширенной статистики (по умолчанию включено)
- Сохранить обратную совместимость: без флага минимальная статистика (mean ± std + графики) остаётся как есть

## Capabilities

### New Capabilities
- `enriched-report-stats`: Расширенная дескриптивная статистика (медиана, IQR, процентили, min/max) для каждой метрики в сводной таблице
- `enriched-report-boxplots`: Box-plot графики распределения метрик по алгоритмам на Chart.js
- `enriched-report-scatter`: Per-sample scatter plot — разброс метрик с подсветкой выбросов
- `enriched-report-significance`: Статистический тест (Wilcoxon signed-rank) для парного сравнения алгоритмов
- `enriched-report-winner-table`: Таблица доли побед алгоритма по снимкам для каждой метрики
- `enriched-report-outliers`: Детекция и таблица выбросов (снимки за ±3σ)
- `enriched-report-json-export`: Экспорт полной статистики в JSON
- `enriched-report-cli-flags`: CLI-флаг `--stats` для управления расширенной статистикой

### Modified Capabilities
- `algorithm-testing`: HTML-отчёт `generate_report` изменяет сигнатуру: добавляет параметры `include_stats`, `include_boxplots`, `include_scatter`, `include_significance`, `include_outliers` (все по умолчанию `True`)
- `classical-baseline-evaluation`: JSON-экспорт `export_json` дополняется медианой, IQR, процентилями, p-value

## Impact

- `testing/dashboard.py` — основная переработка: новые разделы HTML, новые чарты, расширенная сводная таблица
- `testing/runner.py` — `compute_summary()` расширяется для включения дополнительных статистических показателей; новый `compute_percentiles()`, `detect_outliers()`, `wilcoxon_test()`
- `testing/__main__.py` — новые CLI-флаги
- `testing/baseline.py` — JSON-схема экспорта расширяется
- `testing/metrics.py` — без изменений (метрики уже считаются корректно)
- Зависимости: Chart.js остаётся (версия 4.4.7), новых внешних библиотек не требуется — статистика считается на NumPy/Python stdlib
