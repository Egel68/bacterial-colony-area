Напиши код на Python. Приложение должно иметь графический интерфейс. При запуске открывается окно, на котором есть строка с указанием пути к файлу, кнопка "Открыть" и кнопка "Анализировать". Как только выбран файл, кнопка "Анализировать" становится активной. В качестве файла может быть передана только картинка в разных форматах. При нажатии на кнопку "Анализировать" открытие следующего окна, на котором выводится полученая картинка. Если файл не выбран или выбран неверный файл, выводится сообщение об ошибке и что поддерживаются только определенные форматы файлов.

По задумке, приложение должно анализировать изображение бактериальной колонии и определять ее размеры и форму. Изображения всегда однотипные. На них изображена чашка петри, которая сфотографирована на черном фоне. Сама чашка Петри имеет форму круга с определенным диаметром. На ней растут бактерии. Нужно посчитать площаль колоний бактерий на ней, относительно площади самой чашки Петри. Программа должна находить края чашки Петри от фона, находить ее площадь и вычислять площадь бактериальной колонии. Мне хочется, чтобы программа по нажатию отдельной кнопки на новом окне, где будет выведено изображение, будет переключатель, который при использовании будет закрашивать бактериальную колонию в какой-то отдельный цвет. Нужно написать алгоритм, как будет определяться где находится колония бактерий. На этом окне также должна быть кнопка "Вывести площадь колонии", которая будет выводить площадь бактериальной колонии на экран.

Графический интерфейс должен быть сделан с помощью библиотеки PYQT. Самостоятельно сделай графический интерфейс красивым и удобным для пользователя.

Раздели код на модули. Сколько модулей нужно создать реши самостоятельно. Наверное, должен быть модуль для анализа изображения, модуль для отображения графического интерфейса и модуль для вычисления площади колонии бактерий. Запуск приложения должен быть реализован в отдельном модуле с названием main.py.
