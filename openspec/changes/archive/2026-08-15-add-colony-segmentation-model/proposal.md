# Proposal: add-colony-segmentation-model

## Why

Проекту не хватает крупного размеченного датасета для обучения U-Net: текущие маски собираются вручную через labelling-инструмент, их мало. Датасет `datasets/22022540` содержит **369 изображений чашек Петри и 56 865 аннотированных колоний по 24 видам** (COCO/TSV/YOLO/VOC) — этого достаточно, чтобы обучить бинарную сегментацию «есть колония / нет колонии». Нужно корректно привести эти данные к контракту обучения проекта и интегрировать обученную модель как один из алгоритмов распознавания.

## What Changes

- **Новый импортёр** `CocoBboxImporter`, приводящий `datasets/22022540` к контракту данных проекта:
  - растризация боксов колоний → бинарные маски (255 = колония);
  - полноразмерные снимки (`kind=source`) с геометрией чашки Петри в `dish`;
  - опционально вариант `kind=cropped` — обрезка по чашке с чёрным фоном (как в пайплайне разметки);
  - материализация самодостаточной папки датасета (`storage="copy"`) с `dataset.json`, читаемой существующим `ManifestAdapter`.
- **CLI-вход** `import-22022540` для запуска импортёра.
- **Обучение** бинарной сегментационной CNN (U-Net) на этом датасете через существующий `train.main train`, на выходе `best.onnx`.
- **Интеграция модели**: обученный `best.onnx` помещается в `models/` → автоматически регистрируется в реестре алгоритмов как `OnnxModelAlgorithm` через существующий механизм bundled-моделей; либо загружается как внешняя модель через GUI/CLI. Модель определяет **наличие колонии** (бинарная маска), а не класс бактерии.
- **Варианты совместимости** рассмотрены в design: bundled ONNX (без изменения кода), внешний ONNX, новый адаптер под сигнатуру выходной маски.

## Capabilities

### New Capabilities
- `coco-bbox-importer`: импорт внешнего датасета в формате детекции (COCO bbox) в контракт данных проекта — растризация боксов в бинарные маски, файлы `kind=source`/`cropped`, материализация папки с `dataset.json`.

<!-- Нет: интеграция использует существующие neural-model-algorithms и unet-training без изменения их требований. -->

## Impact

- **Код**: `train/dataset_adapters.py` (новый `CocoBboxImporter`), `train/__main__.py` или отдельный CLI (`import-22022540`), возможный скрипт конфигурации обучения.
- **Данные**: источник `datasets/22022540` (read-only); результат — новая самодостаточная папка датасета (например `datasets/22022540_imported/`) с `dataset.json`.
- **Модель**: новый файл `models/*.onnx` (bundled) — отслеживается в git по конвенции проекта.
- **Системы**: тренировка использует `.venv-full` (torch + onnxruntime); инференс в рантайме не требует новых зависимостей.
